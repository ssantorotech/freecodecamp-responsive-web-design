# Recipe Page

A simple recipe webpage created while progressing through the **freeCodeCamp Responsive Web Design** curriculum.

## 📚 What I learned

This project builds on the HTML fundamentals from my previous project and focuses on organizing information into a structured webpage.

I practiced:

* Semantic HTML structure
* Headings and paragraphs
* Ordered and unordered lists
* Images
* Links
* Organizing information into sections
* Creating readable and accessible content

## 🛠️ Technologies

* HTML5

## 🎯 Purpose

The purpose of this project was to practice creating a complete webpage using only HTML while focusing on clear content structure.

## 🚀 Features

The page contains:

* Recipe information
* Ingredients
* Preparation steps
* Images
* Structured sections
