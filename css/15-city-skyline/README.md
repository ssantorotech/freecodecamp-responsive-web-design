# City Skyline

A city skyline illustration created using HTML and CSS as part of the **freeCodeCamp Responsive Web Design v9** curriculum.

## 📚 What I Learned

In this project, I practiced CSS concepts such as:

* CSS variables
* CSS gradients
* `linear-gradient()`
* `repeating-linear-gradient()`
* CSS pseudo-elements
* `::before` and `::after`
* Element positioning
* `position: absolute`
* Width and height
* Borders
* Backgrounds
* Responsive design
* Media queries

## 🎯 Objective

The goal of this project was to create a city skyline illustration using only HTML and CSS.

The project focuses on using gradients, CSS variables, positioning, and pseudo-elements to create buildings, windows, and other visual details without relying on external images.

## 🛠️ Technologies Used

* HTML5
* CSS3
* CSS Variables
* CSS Gradients
* CSS Media Queries

## ✨ Main Features

* CSS-based city skyline illustration
* Multiple building structures
* Building windows created with gradients
* `repeating-linear-gradient()` patterns
* CSS variables for reusable colors
* Pseudo-elements for additional details
* Responsive skyline layout
* Different visual effects for buildings and windows
* No external images required
