Page of Playing Cards

A page displaying a playing card layout created as part of the freeCodeCamp Responsive Web Design v9 curriculum.

🎯 Objective

The goal of this project was to create a page displaying playing cards using CSS Flexbox.

The project focuses on using nested flex containers to organize the different sections of a playing card and position its elements correctly.
