# Blog Post Card

A simple blog post card created as part of the **freeCodeCamp Responsive Web Design v9** curriculum.

## 📚 What I Learned

In this exercise, I practiced CSS concepts such as:

* CSS selectors
* Classes
* Colors and backgrounds
* The CSS box model
* Margins and padding
* Borders and border radius
* Width and height
* Typography
* Image styling
* Basic card layout

## 🎯 Objective

The goal of this exercise was to create and style a blog post card using HTML and CSS.

The project focuses on using CSS to control the layout, spacing, typography, colors, and visual appearance of a reusable content card.

## 🛠️ Technologies Used

* HTML5
* CSS3

## ✨ Main Features

* Blog post card layout
* Cover image
* Styled title and text content
* Styled "Read More" link
* Custom spacing and typography
* Borders and rounded corners
* CSS box model implementation
