# Piano

A piano interface created using HTML and CSS as part of the **freeCodeCamp Responsive Web Design v9** curriculum.

## 📚 What I Learned

In this project, I practiced CSS concepts such as:

* CSS Flexbox
* Element positioning
* CSS selectors
* Width and height
* Margins and padding
* Borders
* Background colors
* Responsive design
* Media queries
* Creating visual layouts with CSS

## 🎯 Objective

The goal of this project was to create a piano interface using HTML and CSS.

The project focuses on using CSS layout techniques and responsive design to recreate the visual structure of a piano.

## 🛠️ Technologies Used

* HTML5
* CSS3
* CSS Flexbox

## ✨ Main Features

* Piano keyboard layout
* Styled piano keys
* CSS-based visual design
* Flexbox layout
* Responsive behavior
* Media query for smaller screens
* Structured HTML elements
