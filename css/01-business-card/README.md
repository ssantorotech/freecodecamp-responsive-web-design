# Business Card

A simple business card webpage created as part of the **freeCodeCamp Responsive Web Design v9** curriculum.

## 📚 What I Learned

In this exercise, I practiced fundamental CSS concepts, including:

* CSS selectors
* Classes and IDs
* Colors and backgrounds
* The CSS box model
* Margins and padding
* Borders
* Width and height
* Typography and text styling
* Basic layout and positioning

## 🎯 Objective

The goal of this exercise was to create and style a digital business card using HTML and CSS.

The project focuses on applying CSS properties to control the appearance, spacing, sizing, and overall layout of the card.

## 🛠️ Technologies Used

* HTML5
* CSS3

## ✨ Main Features

* Structured business card layout
* Styled profile information
* Custom colors and backgrounds
* Spacing and sizing using the CSS box model
* Styled borders and typography
* Basic responsive considerations
