# Nutrition Label

A nutrition facts label created as part of the **freeCodeCamp Responsive Web Design v9** curriculum.

## 📚 What I Learned

In this exercise, I practiced CSS concepts such as:

* CSS typography
* Font families and font sizes
* Font weights
* Text alignment
* Line height
* Margins and padding
* Borders
* Width and height
* Flexbox
* CSS selectors
* Precise spacing and layout

## 🎯 Objective

The goal of this exercise was to recreate a nutrition facts label using HTML and CSS.

The project focuses on using typography, spacing, borders, and alignment to accurately reproduce a structured information layout.

## 🛠️ Technologies Used

* HTML5
* CSS3

## ✨ Main Features

* Structured nutrition facts layout
* Styled nutritional information
* Different font sizes and weights
* Precise text alignment
* Section dividers and borders
* Consistent spacing
* Responsive sizing
