# Rothko Painting

A CSS-based abstract painting inspired by the style of Mark Rothko, created as part of the **freeCodeCamp Responsive Web Design v9** curriculum.

## 📚 What I Learned

In this exercise, I practiced CSS concepts such as:

* The CSS box model
* Width and height
* Margins and padding
* Borders
* Background colors
* Border radius
* Box shadows
* CSS positioning
* Transformations and visual effects

## 🎯 Objective

The goal of this exercise was to recreate an abstract painting using only HTML and CSS.

The project focuses on understanding how the CSS box model and different styling properties can be combined to create complex visual compositions without using images.

## 🛠️ Technologies Used

* HTML5
* CSS3

## ✨ Main Features

* Abstract painting created with CSS
* Multiple colored sections
* Layered elements
* Custom spacing and dimensions
* Box shadows and visual effects
* CSS-based composition without external images
