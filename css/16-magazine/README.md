# Magazine

A responsive magazine-style webpage created using HTML and CSS as part of the **freeCodeCamp Responsive Web Design v9** curriculum.

## 📚 What I Learned

In this project, I practiced CSS concepts such as:

* CSS Grid
* `display: grid`
* Grid columns and rows
* `grid-template-columns`
* `grid-template-rows`
* Grid gaps
* Grid item positioning
* CSS Flexbox
* Typography
* Margins and padding
* Responsive design
* Media queries
* Layout organization

## 🎯 Objective

The goal of this project was to create a magazine-style webpage using HTML and CSS.

The project focuses on combining CSS Grid and Flexbox to organize articles, images, headings, and other content into a structured and responsive layout.

## 🛠️ Technologies Used

* HTML5
* CSS3
* CSS Grid
* CSS Flexbox
* CSS Media Queries

## ✨ Main Features

* Magazine-style layout
* CSS Grid-based page structure
* Multiple rows and columns
* Article and content sections
* Responsive layout
* Typography and text styling
* Organized image and content placement
* Media queries for different screen sizes
