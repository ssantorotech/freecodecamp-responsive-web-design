# Cat Painting

A cat painting created using HTML and CSS as part of the **freeCodeCamp Responsive Web Design v9** curriculum.

## 📚 What I Learned

In this project, I practiced CSS concepts such as:

* CSS positioning
* `position: absolute`
* `position: relative`
* CSS shapes
* Borders and border radius
* Width and height
* Background colors
* Pseudo-elements
* Layering elements
* CSS selectors
* Precise positioning

## 🎯 Objective

The goal of this project was to create a cat illustration using only HTML and CSS.

The project focuses on using CSS shapes, positioning, borders, and layering to build the different parts of the cat.

## 🛠️ Technologies Used

* HTML5
* CSS3

## ✨ Main Features

* Cat illustration created entirely with CSS
* Custom CSS shapes
* Absolute and relative positioning
* Layered elements
* Styled eyes, ears, nose, and head
* Borders and rounded shapes
* No external images required
