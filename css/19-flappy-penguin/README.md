# Flappy Penguin

A CSS-based animated penguin illustration created as part of the **freeCodeCamp Responsive Web Design v9** curriculum.

## 📚 What I Learned

In this project, I practiced CSS concepts such as:

- CSS animations
- `@keyframes`
- CSS transforms
- `transform-origin`
- Element positioning
- `position: absolute` and `position: relative`
- CSS variables
- Pseudo-elements
- Creating shapes with CSS
- Layering elements
- Backgrounds and gradients
- Animation timing and movement

## 🎯 Objective

The goal of this project was to create a penguin illustration using HTML and CSS, then bring it to life with CSS animations.

The project focuses on combining CSS shapes, positioning, and transformations to build the penguin's body and facial features, while using animations to create movement.

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Animations
- CSS Transforms
- CSS Variables

## ✨ Main Features

- Penguin illustration created with CSS
- Custom shapes and layered elements
- Styled facial features and body
- CSS transformations for movement
- Keyframe-based animations
- Positioning of individual illustration elements
- No JavaScript required for the animation
