# Ferris Wheel

A Ferris wheel animation created using HTML and CSS as part of the **freeCodeCamp Responsive Web Design v9** curriculum.

## 📚 What I Learned

In this project, I practiced CSS concepts such as:

* CSS animations
* `@keyframes`
* `transform`
* `transform-origin`
* `rotate()`
* Element positioning
* `position: absolute`
* CSS selectors
* Borders
* Background colors
* Creating circular shapes
* Animation timing

## 🎯 Objective

The goal of this project was to create an animated Ferris wheel using HTML and CSS.

The project focuses on using CSS transformations and animations to rotate the Ferris wheel and create the movement of its individual cabins.

## 🛠️ Technologies Used

* HTML5
* CSS3
* CSS Animations
* CSS Transforms

## ✨ Main Features

* CSS-based Ferris wheel
* Rotating wheel animation
* Animated cabins
* CSS-created circular structure
* `@keyframes` animation
* `transform` and `transform-origin`
* Absolute positioning
* No JavaScript required
