# Flexbox Photo Gallery

A responsive photo gallery created as part of the **freeCodeCamp Responsive Web Design v9** curriculum.

## 📚 What I Learned

In this exercise, I practiced CSS concepts such as:

* CSS Flexbox
* `display: flex`
* `flex-direction`
* `flex-wrap`
* `justify-content`
* `align-items`
* Flexbox alignment and spacing
* Responsive layouts
* Image sizing
* The CSS box model

## 🎯 Objective

The goal of this exercise was to create a responsive photo gallery using CSS Flexbox.

The project focuses on using Flexbox to arrange images into a flexible layout that adapts to different screen sizes.

## 🛠️ Technologies Used

* HTML5
* CSS3
* CSS Flexbox

## ✨ Main Features

* Responsive photo gallery
* Flexible image layout
* Flexbox-based positioning
* Automatic wrapping of images
* Consistent spacing between elements
* Images adapted to the available space
