# Pricing Plans Layout

A responsive pricing plans layout created as part of the **freeCodeCamp Responsive Web Design v9** curriculum.

## 📚 What I Learned

In this exercise, I practiced CSS concepts such as:

* CSS Flexbox
* `display: flex`
* `flex-direction`
* `justify-content`
* `align-items`
* `gap`
* Flexible widths
* Responsive layouts
* Margins and padding
* Borders and border radius
* Typography and text styling

## 🎯 Objective

The goal of this exercise was to create a pricing plans layout using CSS Flexbox.

The project focuses on arranging multiple pricing cards in a flexible layout while maintaining consistent spacing, sizing, and alignment.

## 🛠️ Technologies Used

* HTML5
* CSS3
* CSS Flexbox

## ✨ Main Features

* Multiple pricing plan cards
* Flexbox-based layout
* Consistent spacing and alignment
* Pricing and feature information
* Styled buttons and elements
* Responsive layout structure
* Borders and rounded corners
