# CSS

This folder contains the exercises, labs, workshops, and projects completed during the **CSS section** of the **freeCodeCamp Responsive Web Design v9** curriculum.

The goal of this section is to build a solid foundation in CSS and progressively learn how to create well-structured, styled, and responsive web pages.

## 📚 Topics Covered

Throughout this section, I will practice concepts such as:

* CSS syntax and rules
* Selectors
* Classes and IDs
* Colors and backgrounds
* The CSS box model
* Margins and padding
* Borders
* Width and height
* Typography and text styling
* Positioning
* Flexbox
* CSS Grid
* Responsive design
* Media queries
* Animations
* Layout and visual styling

## 📁 Projects

Projects completed in this section are organized into separate folders:

```text
css/
├── 01-business-card/
├── ...
└── ...
```

Each project may contain its own `README.md` with details about the exercise, concepts learned, technologies used, and project structure.

## 🎯 Learning Approach

The exercises are completed following the order of the **Responsive Web Design v9** curriculum.

For each project, the goal is not only to complete the requirements but also to understand the CSS concepts and techniques used to build the page.

## 🛠️ Technologies

* HTML5
* CSS3
