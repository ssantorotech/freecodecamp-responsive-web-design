# Event Flyer Page

A simple event flyer webpage created as part of the **freeCodeCamp Responsive Web Design v9** curriculum.

## 📚 What I Learned

In this exercise, I practiced CSS concepts such as:

* CSS selectors
* Classes and IDs
* Relative and absolute units
* Colors and backgrounds
* Typography
* Margins and padding
* Borders
* Width and height
* Basic layout and positioning

## 🎯 Objective

The goal of this exercise was to create and style an event flyer page using HTML and CSS.

The project focuses on using different CSS units and styling techniques to create a structured and visually appealing event page.

## 🛠️ Technologies Used

* HTML5
* CSS3

## ✨ Main Features

* Event flyer layout
* Event information and details
* Styled headings and text
* Images and visual elements
* Custom colors and backgrounds
* Responsive sizing using CSS units
* Spacing and layout adjustments
