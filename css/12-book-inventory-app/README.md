# Book Inventory App

A book inventory interface created as part of the **freeCodeCamp Responsive Web Design v9** curriculum.

## 📚 What I Learned

In this project, I practiced CSS concepts such as:

* CSS selectors
* Attribute selectors
* CSS classes
* Flexbox
* Spacing and alignment
* Margins and padding
* Borders
* Background colors
* Typography
* Styling links and buttons
* Responsive layout techniques

## 🎯 Objective

The goal of this project was to create a book inventory interface using HTML and CSS.

The project focuses on organizing book information into a structured layout and applying CSS styling to create a clear and consistent user interface.

## 🛠️ Technologies Used

* HTML5
* CSS3
* CSS Flexbox

## ✨ Main Features

* Book inventory layout
* Structured book information
* Styled book categories and statuses
* Consistent spacing and alignment
* Custom typography and colors
* CSS-based interface styling
* Responsive layout structure
