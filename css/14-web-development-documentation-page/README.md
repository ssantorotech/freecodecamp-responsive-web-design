# Web Development Documentation Page

A responsive web development documentation page created as part of the **freeCodeCamp Responsive Web Design v9** curriculum.

The original Technical Documentation Page was expanded into a broader **Web Development Documentation** page covering multiple technologies.

## 📚 What I Learned

In this project, I practiced CSS concepts such as:

* Fixed positioning
* Responsive layouts
* Media queries
* CSS pseudo-classes
* Navigation styling
* Spacing with margins and padding
* Borders
* Colors and typography
* `height: 100vh`
* `z-index`
* `scroll-margin-top`
* Responsive navigation
* Structuring content into sections

## 🎯 Objective

The goal of this project was to create a documentation-style webpage with a fixed navigation menu and multiple content sections.

The page was expanded to cover the following web development topics:

* Introduction
* HTML
* CSS
* JavaScript
* Java

The project focuses on creating a clear documentation structure while adapting the layout for smaller screens using CSS media queries.

## 🛠️ Technologies Used

* HTML5
* CSS3
* CSS Media Queries

## ✨ Main Features

* Fixed navigation sidebar
* Navigation links connected to documentation sections
* Five documentation sections
* Introduction to HTML, CSS, JavaScript, and Java
* Code examples using `<code>` elements
* Lists containing key concepts
* Hover effects on navigation links
* Responsive navigation for smaller screens
* Mobile layout using a media query
* `z-index` to keep the navigation above the content
* `scroll-margin-top` for improved section navigation on mobile
