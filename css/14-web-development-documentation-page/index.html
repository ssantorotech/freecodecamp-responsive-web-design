Introduction

Web development is the process of creating and maintaining websites and web applications.

It usually involves several technologies that work together to create the structure, style, and behavior of a webpage.

<html> Web page structure </html>
  • HTML defines the structure of a webpage.
  • CSS controls the visual appearance of a webpage.
Html

HTML stands for HyperText Markup Language and is used to create the structure of web pages.

HTML uses elements such as headings, paragraphs, links, images, and lists to organize content.

<h1>Hello World</h1>
  • HTML elements are usually written using opening and closing tags.
  • HTML attributes provide additional information about elements.
Css

CSS stands for Cascading Style Sheets and is used to style HTML elements.

CSS can control colors, fonts, spacing, borders, layouts, and many other visual properties.

p { color: blue; }
  • CSS can be used to change the appearance of text.
  • CSS can be used to create flexible page layouts.
Javascript

JavaScript is a programming language commonly used to add interactivity to web pages.

It can respond to user actions and dynamically change the content of a webpage.

console.log("Hello World");
  • JavaScript can respond to events such as clicks.
  • JavaScript can modify HTML and CSS through the DOM.
Java

Java is a general-purpose programming language used to build many different types of applications.

It is different from JavaScript, despite their similar names.

System.out.println("Hello World");
  • Java is commonly used for backend and enterprise applications.
  • Java programs are compiled into bytecode that runs on the Java Virtual Machine.
