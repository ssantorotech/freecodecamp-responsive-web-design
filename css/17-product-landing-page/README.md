# Product Landing Page — SONORA

A responsive product landing page for **SONORA One**, a fictional premium wireless headphones brand, created as a **Certification Project** for the freeCodeCamp Responsive Web Design v9 curriculum.

The project focuses on building a modern product page with clear navigation, product features, an embedded video, pricing information, and an email subscription form.

## 📚 What I Learned

In this project, I practiced HTML and CSS concepts such as:

- Semantic HTML structure using `header`, `nav`, `main`, `section`, `article`, and `footer`
- Fixed positioning with `position: fixed`
- Flexbox for navigation, alignment, and layout
- CSS Grid for feature cards
- CSS custom properties using `:root` and `var()`
- Responsive typography with `clamp()`
- Responsive layouts using media queries
- CSS functions such as `min()` and `calc()`
- Smooth scrolling with `scroll-behavior`
- Scroll offset management with `scroll-padding-top` and `scroll-margin-top`
- Hover and focus states using `:hover` and `:focus-visible`
- CSS transitions and interactive visual effects
- Styling forms and validating email input with HTML
- Embedding external video content using `iframe`
- Image styling with `object-fit` and `object-position`
- Layout proportions with `aspect-ratio`
- Visual hierarchy through spacing, typography, and color contrast

## 🎯 Objective

The goal of this project was to build a product landing page that presents a fictional product in a clear, engaging, and responsive way.

The page was designed around the SONORA One wireless headphones and organized into distinct sections:

- **Home:** introduces the product with a headline, description, call-to-action, and product image.
- **Features:** presents three key product benefits using a grid of feature cards.
- **Experience:** introduces the listening experience and includes an embedded video.
- **Pricing:** displays the product price and its main features.
- **Newsletter:** provides an email form for users who want product updates.

The project also applies responsive design principles to adapt the navigation, feature grid, pricing card, and form to smaller screens.

## ✨ Main Features

- Fixed header with brand identity and navigation links
- Navigation links connecting the page's main sections
- Dark color palette with a blue accent
- Hero section with responsive typography and product imagery
- Three-column feature grid that becomes a single column on smaller screens
- Embedded video with a responsive 16:9 aspect ratio
- Pricing card featuring an illustrative €149.00 price
- Newsletter form with an email input and submit button
- Smooth scrolling and section offset for fixed-header navigation
- Hover transitions and visible keyboard-focus styling
- Responsive layouts for tablet and mobile screen sizes
- Reusable CSS variables for colors, typography, spacing, and layout values
