# Colored Markers

A simple webpage featuring colored markers created as part of the **freeCodeCamp Responsive Web Design v9** curriculum.

## 📚 What I Learned

In this exercise, I practiced CSS concepts such as:

* CSS selectors
* Classes
* RGB colors
* HEX colors
* HSL colors
* Linear gradients
* Background colors
* Borders
* Box shadows

## 🎯 Objective

The goal of this exercise was to create and style colored markers using different CSS color formats and styling techniques.

The project focuses on understanding how colors can be represented and combined with gradients and other CSS properties.

## 🛠️ Technologies Used

* HTML5
* CSS3

## ✨ Main Features

* Multiple colored markers
* RGB, HEX, and HSL color values
* Linear gradients
* Styled marker elements
* Box shadows
* CSS-based visual effects
