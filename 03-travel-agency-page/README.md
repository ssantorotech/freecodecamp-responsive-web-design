# Travel Agency Page

A travel agency webpage created as part of my **freeCodeCamp Responsive Web Design** learning path.

## 📚 What I learned

This project allowed me to practice structuring a webpage around a real-world use case.

Key concepts practiced:

* HTML document structure
* Semantic content organization
* Headings and paragraphs
* Images
* Links
* Lists
* Grouping related content
* Structuring a webpage for usability

## 🛠️ Technologies

* HTML5

## 🎯 Purpose

The goal was to create a basic travel agency webpage containing information about destinations and travel options.

This project helped me understand how HTML can be used to structure content that could later be styled and transformed into a complete responsive website.

## 🚀 Features

* Travel destination information
* Destination images
* Navigation links
* Structured travel content
* Organized sections

## 📖 Learning source

Built while following the **freeCodeCamp Responsive Web Design** curriculum.

Continue strengthening my HTML fundamentals and prepare for more advanced topics such as CSS layouts and responsive design.
