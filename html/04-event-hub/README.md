# Event Hub

A simple event listing webpage built as part of my **freeCodeCamp Responsive Web Design** learning path.

## 📚 What I learned

This project focuses on structuring information for multiple events using HTML.

I practiced:

* Semantic HTML
* Headings
* Paragraphs
* Lists
* Links
* Images
* Sections
* Organizing repeated content
* Structuring a webpage around different types of information

## 🛠️ Technologies

* HTML5

## 🎯 Purpose

The goal of this project was to create a webpage that presents upcoming and past events in a clear and organized way.

It helped me understand how HTML structure can be used to represent real-world content before applying CSS for visual design.

## 🚀 Features

* Upcoming events section
* Past events section
* Event information
* Event images
* Structured content
* Navigation links

## 📖 Learning source

Built as part of the **freeCodeCamp Responsive Web Design** curriculum.

## 🔜 Next step

Continue with HTML and accessibility concepts before applying CSS to improve the layout and responsive behavior.
