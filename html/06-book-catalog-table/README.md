# Book Catalog

A basic book catalog webpage created as part of my **freeCodeCamp Responsive Web Design** learning path.

## 📚 What I learned

This project focuses on organizing structured information using HTML.

I practiced:

* HTML tables
* Table headers and rows
* Structured data
* Headings
* Links
* Images
* Semantic HTML
* Organizing repeated information

## 🛠️ Technologies

* HTML5

## 🎯 Purpose

The goal was to create a simple catalog for displaying information about multiple books.

This project helped me understand how HTML can represent structured data in a way that is readable and organized.

## 🚀 Features

* Book listings
* Book information
* Structured catalog layout
* Links
* Images
* Tabular data

Built as part of the **freeCodeCamp Responsive Web Design** curriculum.
